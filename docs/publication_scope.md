# Co publikować, a czego nie publikować

## Publikować

- opis środowiska sprzętowego i programowego,
- ustawienia renderowania,
- listę CVar i ich wartości,
- warianty eksperymentalne,
- procedurę pomiarową,
- sposób analizy danych,
- wyniki referencyjne,
- zweryfikowane wyniki referencyjne wykorzystane w pracy,
- opis warunków budowy równoważnych scen testowych.

## Nie publikować

- pełnego projektu UE,
- pełnego kodu programu,
- kompletnych Blueprintów,
- całych assetów licencjonowanych,
- danych lub plików, których licencja nie pozwala redystrybuować.

## Uzasadnienie

Reprodukowalność badania nie wymaga automatycznie publikacji kompletnego rozwiązania.
W tym przypadku istotne jest udokumentowanie warunków pomiaru, konfiguracji wariantów,
procedury oraz sposobu analizy. Repozytorium ma umożliwić zbudowanie równoważnego
eksperymentu i zweryfikowanie zależności opisanych w pracy, bez przekazywania kompletnego,
gotowego projektu.
